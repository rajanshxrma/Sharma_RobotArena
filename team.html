Roles & Responsibilities

Solo project, so every role below is Rajan. Splitting the work into roles kept each Kanban card small and made it clear which hat I was wearing.

Role 01

UI / UX Designer

  • Picked the dark HUD palette and the orange/cyan accents
  • Set up the CSS variables (colors, type scale, spacing)
  • Wireframed all five pages, desktop and mobile
  • Chose the three font roles: headings, body, data
Role 02

Layout Developer

  • Built the semantic HTML for every page
  • Grid for page sections, Flexbox for rows and controls
  • Mobile-first breakpoints at 640px and 960px
  • CSS-only menu toggle for small screens
Role 03

CSS Animation Specialist

  • Keyframes for pulse, scan, ticker, power-up flash and countdown
  • Hover and focus transitions on cards and buttons
  • Arena Cam scan and result sequence
  • Reduced-motion fallback for all of it
Role 04

QA & Accessibility Tester

  • Checked 375, 768 and 1280px widths
  • Keyboard-only run through every page
  • Checked contrast, alt text and heading order
  • Checked links and assets before upload

Daily Stand-up

Format

Solo, so the stand-up is a written 10 minute check-in at the start of each work block. The answers go in the development journal and the Kanban board gets updated right after.

Three questions

  1. What did I finish last block?
  2. What am I working on now?
  3. Anything blocking me?

Output

  • Kanban cards moved
  • Decisions written down
  • A commit with a clear message
